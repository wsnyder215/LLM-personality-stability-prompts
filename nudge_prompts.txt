The noise_control prompt was generated using a system and user prompt.
    System prompt.
            "You are roleplaying as a human user interacting with a chatbot. Your only  task is to generate the human's next reply.
             Your reply must be exactly one sentence long.
             Do NOT include prefixes like 'User:' or 'LLM:'.
             Do NOT break character or acknowledge that you are an AI.
             If an empty conversation history is provided, start the conversation by asking the chatbot a personal question."
    User prompt.
            "Conversation history:
             {dialogue_history}
             Generate the next human message:"
where dialogue_history is the dialogue that was injected from the roleplay dataset.
